## ¿Por qué crear una nueva página web?

La razón es simple, me gusta aprender nuevas tecnologías, yo hace 6 años creé mi página web con HTML, CSS y JavaScript (lo típico al inicio), 
pero ya viendo que existen nuevas tecnologías de front end para crearlas pues decidí invertir mi tiempo en hacerla.
Cabe aclarar que esta página la he hecho en un 90% con código propio (investigando, recordando cosas) y el otro 10% son bugs súper pesados que 
sinceramente no sabía por dónde encontrar mis errores y tuve que apoyarme en la IA como herramienta para que me explique y ayude con la solución.
<br />
Esta web siempre le voy a tener mucho cariño, porque me ha costado mucho esfuerzo, varios días y he ganado bastante aprendizaje que era el objetivo principal.


## ¿Qué tecnologías he usado para la web?

### Para Diseño: Figma
Primero aprendí a usar Figma, quería plasmar de forma rápida mi idea de página web (equivocadamente), hacer mis diseños en Figma me ha tomado muchos días, mis respetos para los diseñadores UX/UI porque me ha costado entender incluso las cosas básicas de ese software.
<br />
### Bases: HTML, CSS, JavaScript
Bueno, esto ya lo conocía, básicamente con esto armamos el esqueleto de la web y le damos los estilos bonitos respectivos.
Lo que sí profundicé un poco más es con CSS para el tema de algunas animaciones, backgrounds personalizados. 
<br />
### Lenguaje: TypeScript
Aquí no había mucha alternativa, era JavaScript puro o TypeScript (el cual luego compila JavaScript).
Con TypeScript lo que se gana es que podemos ver errores del código en el editor antes de ejecutarlo.
<br />
### CSS Framework: TailwindCSS
Aquí sí fue totalmente nuevo para mi, no estaba al tanto de que ya podríamos manejar de formas más flexibles configuraciones visuales desde el mismo ClassName de los elementos web.
Algo que me ha ayudado bastante esta tecnología fue poder separar muy bien los breakpoints para el responsive design, me ha gustado.
Lo que sí hay que estar investigando en su web: https://tailwindcss.com/ cómo se traduce un estilo de CSS a su correspondiente atajo de TailwindCSS.
<br />
### React Framework: Next.js
Cuando decidí crear la web, revisé actualmente cuál es la librería más popular para JavaScript para usar y vi que era React, entonces decidí usar su framework Next.js.

### MDX 
Para armar estos blogs estoy usando el formato .mdx (Markdown + JSX) con eso en los blogs podemos usar componentes React y hacerlos más vistosos, ya en próximos blogs los empezaré a usar, en este blog solo usé el componente de BlogImage.
<br />
### Supabase
De supabase solo estoy usando la parte de base de datos, en la que almaceno los likes que puedan recibir los post, asociado a un ID + Post, cosa que si otro día vuelven a entrar al post seguirá el like ahí.
<br />
### Giscus
Esto es prácticamente habilitar la opción de Discussions en Github (En el repositorio que queremos) y luego se pueda asociar Giscus con dicho repositorio y te habilita un script que puedes usarlo en tus post.
Claro, aunque la única desventaja es que para comentar tienes que tener creada una cuenta en Github.
<br />
### Vercel
Por último Vercel para poder desplegarlo y en un corto plazo voy a alquilar mi dominio .com para poder asociarlo, pero poco a poco.
